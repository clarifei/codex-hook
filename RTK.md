# RTK

Token-optimized CLI proxy. Always prefix shell commands with `rtk`.

Examples: `rtk git status`, `rtk cargo test`, `rtk npm run build`, `rtk pytest -q`.

Meta: `rtk gain` for savings analytics, `rtk gain --history` for recent savings, `rtk proxy <command>` for raw output.

Verify: `rtk --version`, `rtk gain`, `which rtk`.
